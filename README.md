# Martins Ajayi Portfolio Website

A responsive, buildless project management portfolio for Martins Ajayi, PMP and Professional Scrum Master. The website includes three anonymized reconstructed case studies, detailed delivery documents, practical toolkit material and contact links from the supplied résumé.

Open index.html to view locally. No installation or build step is required. Case documents are embedded in the page and open in keyboard-operable dialogs. Direct GitHub links connect to the portfolio projects.

## GitHub Pages
After the files are on the chosen default branch, select that branch and the root directory under Settings → Pages → Deploy from a branch. Retain .nojekyll. Add the actual live URL to the profile only after GitHub confirms deployment.

## Portfolio integrity
Workplace names are omitted. Detailed budgets, dates, incidents, sample test evidence and outcomes are illustrative reconstructions; they are not verified historical performance claims. The case domains and responsibility themes come from Martins’ résumé.
